# X审判者（X Judge）

**拿 X 自己的现行算法代码和官方规则当法律，让 AI 给你的账号历史帖子逐条判性——哪些合规、哪些危险、哪些该删——最后交给你一个能直接动手清理的审判台。**

本质一句话：**利用 AI 完成对账号维护的数据分析，尽力帮创作者通过 X 的 500K 曝光变现审核（Original Content Rewards）。**

账号过不了审核，往往不是死在某一条大违规上，而是死在历史包袱：协调互动招揽的回复、只谈变现的帖子、成人与仇恨残留——单看都不致命，攒起来就是审核眼里的「负面画像」。X审判者把这些从你成千上万条历史帖里逐条挑出来、判清性质、排好删除顺序，你亲手清掉，以干净状态去申请。

## 它怎么判

- **法条是真的**：依据 X 开源的推荐算法仓库（xai-org/x-algorithm）现行代码 + 官方 Authenticity 政策与 Original Content Rewards 计划页原文。
- **先校准再开工**：执行审判的 AI 必须先做完包内 14 道带标准答案的虚构判例题，全对才许碰真实数据。
- **定罪要验活**：数据包是导出那一刻的快照，包里有 ≠ 平台上还活着；判决依赖存活状态的，先查公开接口核实，查不到记「未果」，不冤判。
- **审判单位是逻辑帖**：被编辑过的帖子先合并版本链再审，不把旧版本当独立帖子误杀。

## 功能（公开版即完整版）

- 完整法条与判定手册：算法权重、平台规则、变现门槛与全部判定边界
- 数据包全量解析：编辑链合并、逻辑帖对账、三侧筛查（内容 / 关系 / 隐私）
- 逐条五档判决（合规 / 低危 / 中危 / 高危 / 违规），每条带法条依据、理由、证据等级与处置建议
- 默认产物「审判台」空间：先建空台，首页是仪表盘，带真实进度条（AI 后台拉包开工，用户不用点任何按钮）；导入后是总览仪表盘 + 异常 / 正常 / 已删除页签，法条与审判台平级一键切换，点卡片直达原帖，勾选即归档
- 取包默认走 Google Drive：没下载过数据包，AI 带你去 X 索取（备包约 24 小时，留断点等你上传成功后回来续跑）；有包后把 zip 上传 Google Drive、授权 AI 读取（云盘实在用不了，才用本地路径或对话附件）；拿到包直接分析、后台建台，全部完成通知你
- 可选导出单文件 HTML

## 开源三原则

1. **不带任何人的隐私**：包内只有判定方法与虚构示例；你的数据包只在你自己的环境里处理。
2. **通用公开版**：这就是唯一正本，作者本人用的也是这一版。
3. **功能满血不阉割**：全部功能都在包里，零经验的 AI 照样跑通全流程。

## 怎么用

1. 把本仓库链接发给你的 AI。
2. 它会自己装好并开跑：学法条、过校准、先问你下载过数据包没有（没有就带你去索取），同时先把你的审判台建好。
3. 按它的指引把数据包上传 Google Drive 给它（云盘用不了时才给本地路径或把 zip 发进对话）——剩下的 AI 在后台自己办：拉包、审判、灌进台子，进度写在首页；全部完成它会通知你。审判台开张后：点卡片直达原帖，亲手删帖，回来勾掉。删除永远由你本人完成，AI 不登录你的账号、不代删。

> 转发给朋友：把仓库链接和这句一起发——「把这个仓库装好，用审判者审一下我的号。」

## 能力边界

- **使用环境**：为 Muse（Personal Agent）设计；云 AI 取包需要连接 Google Drive，本地 agent 可直接读本地文件。
- 判的是「按公开法条的定性」，**不是 X 官方裁决**；官方未公开的机制一律标注「官方未公开」，不猜。
- 只读分析：不登录被审账号、不发帖、不删帖。
- 法条有基线日期（见 `SKILL.md`「法条维护」），X 的算法与规则会变，建议定期对照官方源更新。
